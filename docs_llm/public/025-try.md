## 005 · Choose the current foundation

For current core behavior read [Writing pages](095-writing-pages.md) and [Classes/hosts](090-classes-and-hosts.md). Python Page authors typed Source, while bindings/controllers/resolvers/components remain deferred (*0.2.0:* bindings and controllers released in 0.2.0; try them with the local runner, described in [Writing pages](095-writing-pages.md)). Local examples install package artifacts without sibling-source imports. Historical note: until 2026-09-26 the `gramlot-minimal` repository published an offline showcase on the experimental [gramlot-poc](https://github.com/gramlot-org/gramlot-poc) runtime; the repository is retired and archived, its heirs are `gramlot-uvicorn` and `gramlot-serverless`; the showcase is not maintained and is not an evaluation path. Current standalone integration is `gramlot-serverless`: it runs a JS Page in a Worker through the core shared Host and owns WorkerHost, WorkerTransport, startup and the Node/npm exporter. The old Python/JS compiler is removed.

<a id="gc-025-010"></a>

## 010 · Choose a Host for a page

Python is the first authoring path. Current hosts are Uvicorn/ASGI, [FastAPI](https://github.com/gramlot-org/gramlot-fastapi/blob/main/docs/050-native-html.md), Flask and Kajenn; JS uses Node, Bun or Worker. Use each adapter's documented revision with locally built artifacts; package registries may differ. [Django](https://github.com/gramlot-org/gramlot-django) and [gramlot-poc](https://github.com/gramlot-org/gramlot-poc) remain experimental paths. PoC behavior does not extend the current core API.

## 015 · What to evaluate

For current core, inspect a Python Page, typed Source, marked remote block, live updates, freeze and cleanup. Check server failures, required controls, adapter limits and tolerance for API changes. Read [quality](030-quality.md). *0.2.0:* the acceptance page (Python plus JS equivalent) is `examples/controllers/09_end_to_end` (route `c09`): a title bound to `.settings.caption`, an input, two radios, a checkbox, a computed result, a bound SVG and a button with a nested named `dataController`, with `dataSetter` after some controls. `examples/binding/` (11 pages) and `examples/controllers/` (9 pages) cover each feature alone; evaluate against them.

The core development manual now starts at [Classes and server adapters](090-classes-and-hosts.md). It describes the smaller Gramlot core.

The adapter entry points are FastAPI `NativeHtmlApplication` / `mount_native_html`,
Flask `mount_native_html`, ASGI `NativeHtmlASGI`, Kajenn
`KajennNativeHtmlApplication`, and JS `@gramlot/gramlot-js-server/node` / `@gramlot/gramlot-js-server/bun`.
Use the [Hello World launch profiles](https://github.com/gramlot-org/gramlot-examples/tree/main/apps/hello-world)
with the prepared package artifacts. Legacy `GramlotApplication`, `mount_gramlot`
and PoC launch commands are outside the clean-core contract. Django, the Gramlot site and Rosetta were excluded from the original published
0.1.0 matrix; their PoC capabilities are not implied by that release.


Download the [0.1.0 archive set](https://github.com/gramlot-org/gramlot/releases/tag/v0.1.0).
Extract the complete bundle and follow its README: install all five Python wheels
together in a new environment, or all four npm archives together in a separate
consumer. Dependencies remain floating; internet access is required during setup.
GitHub release assets are the delivery source for this nine-package archive set.
Separately, the JavaScript core was published on JSR as `@genro/gramlot` 0.1.0 on
2026-09-24. That registry publication is not the complete archive set above; its
matching version number does not establish identical contents. Follow the archive
README for this installation path. Later development changes are not implied by
either published 0.1.0 distribution.

Development after 0.1.0 groups these environments into **integration repos**:
`gramlot-fastapi`, `gramlot-flask`, `gramlot-kajenn`, `gramlot-uvicorn`,
`gramlot-js-server` (Node.js and Bun, and the browser/Worker standalone exporter),
and `gramlot-django`. `gramlot-uvicorn` owns Python/ASGI/Uvicorn integration and
`@gramlot/gramlot-browser`, in `gramlot-js-server`, owns browser/Worker standalone
packaging; they replace `gramlot-minimal`, retired on 2026-09-26. `gramlot-kajenn` depends only on Kajenn
besides the core (amendment 11.48 item 5); its adapter is not migrated yet and is
deferred to after 0.2.0. The published 0.1.0 archives and their original installation
instructions remain unchanged.

`gramlot-uvicorn` and `gramlot-js-server` exist locally and on GitHub. `gramlot-kajenn` was renamed from `gramlot-genro-asgi` on 2026-09-26, on GitHub
and locally.
Further package publication remains separate work.

Local development now adds Django integration through `NativeHtmlPages`
and ordinary Django URLconf mounting. It is separate from the
historical Page/ORM integration; no ORM migration is implied.

## 020 · One shared example suite, several integrations

Gramlot is the upstream reference for framework documentation and the shared
teaching suite: pages, READMEs, runner, logo and theme. Read its manual first,
then the chosen integration's guide; clone that downstream repository for its
adapter, configuration and launch instructions. Read the Docs is the documentation
target, not a claim that all integration sites are already published.

Integrations consume Gramlot's examples without maintaining local source copies.
Python runs in Flask/FastAPI/Django/Kajenn or `gramlot-uvicorn`; JavaScript runs
in Node.js/Bun or the browser Worker of `@gramlot/gramlot-browser`. The integration selects the language.
Update the Gramlot dependency, then restart or regenerate the standalone export
to receive changes. Installed environments and exports do not refresh themselves.
Generated assets are outputs, not another source. First-party dependencies remain
unpinned; published 0.1.0 archives are immutable.

Agreed model, not completed ecosystem rollout: sources exist in `examples/html_svg`, `examples/binding` and `examples/controllers`
(one file page per example: `NN_name.py`, `.js`, `.md`, same-name `.css` and logic companion `_aux.js` where needed),
`examples/00-runner` and `themes/gramlot-base`; uniform dependency packaging and
launch commands for all six integrations remain to be implemented and verified.
Historical demos and existing Hello World smoke launchers are separate evidence.

Development naming update: `gramlot-js-server` replaces `gramlot-nodejs` for both Node.js and Bun. Earlier 0.1.0 archive names remain historical.

## 025 · Standalone example download

The ready-to-use example ZIP was distributed through the releases of the retired
`gramlot-minimal` repository (archived 2026-09-26).
The new thirteen-example runner ZIP is not yet published. The core release's
`gramlot-native-0.1.0.zip` contains package artifacts, not this standalone demo.

`@gramlot/gramlot-browser` generates the archive from the shared Gramlot examples, runner and theme,
and records the Gramlot version used. Once available, extract the entire archive
and open its `index.html` in a browser; keep the folder together. No application
server or runtime installation is needed. Rebuild or download a new export to
receive updates; an extracted directory does not update itself.
