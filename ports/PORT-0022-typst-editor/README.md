# PORT-0022 · Typst editor, preview and client PDF

Owner scope (2026-10-21): “bene ora procediamo con typst: editor e anteprima nella ide e un esempio nella gallery, con generazione pdf anche lato client per la versione serverless”.

Evidence: GC-198 §§075–080, the earlier disposable browser qualification of typst.ts 0.7.0, genro-typst native compiler, and the existing IDE Code/Preview composition. This is a bounded browser implementation, not a native compiler port or bulk PoC copy.

Destination review: CodeMirror is the source editor. Optional `typstPreview` reads a Data string and owns only compiled projections, worker lifecycle, diagnostics and download URLs. The IDE retains its Data draft, history, revision-aware host save and dirty state. Python-first gallery page has an equivalent JS page. The Python integration identifies .typ; serverless owns collection packaging shared across routes. No Builder/Bag edits, consumer fallback or server compilation endpoint.

Dependency review: typst.ts/compiler/renderer 0.7.0, CodeMirror Typst Lezer 0.6.0. Native Typst 0.15 and browser 0.14.2 are not declared equivalent. Five unmodified typst-assets fonts include upstream LICENSE/NOTICE; notices are embedded in the optional module. The build embeds WASM/font bytes, so compilation needs no fetch. First-party dependencies remain unconstrained.

Bounded scope: self-contained source, bundled fonts, static SVG and current-draft PDF. Includes/assets from the IDE filesystem and external packages are not loaded. No reverse conversion into Python recipes, LSP, server PDF route or single-HTML collection export. The optional module is roughly 41 MiB uncompressed; initialization is lazy but module transfer is not. Directory export shares collection source once, avoiding per-route compiler duplication.

Status: implemented; local verification completed within accessible tooling, owner trial/acceptance pending. Browser file-origin verification of the new export is blocked by tool policy; do not substitute historical proof for a fresh check. No publication or deployment.
