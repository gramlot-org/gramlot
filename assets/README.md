# Gramlot graphic assets

Start with the [identity kit](branding/README.md) or open the
[offline visual catalogue](branding/index.html) in a browser.

The complete kit as a ZIP (`gramlot-brand-kit.zip`) is generated by
[`branding/source/build_assets.py`](branding/source/README.md); it is not committed.

The canonical vector master, transparent exports, icons, social compositions,
presentation backgrounds, palette and printable guide live in `branding/`.
This directory contains graphic resources, not a Gramlot application or runtime theme.
