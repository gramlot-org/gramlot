# Bundled Typst fonts

Five unmodified fonts from [typst/typst-assets](https://github.com/typst/typst-assets), retrieved 2026-10-21: Libertinus Serif regular/bold/italic, DejaVu Sans Mono regular and New Computer Modern Math regular.

The accompanying upstream LICENSE and NOTICE preserve the individual font licenses. Only these five font files are embedded by `js/scripts/build-typst.mjs`; the complete upstream NOTICE is retained. The optional Typst collection carries the notices inline for offline exports.

Upstream snapshot: `94dcb990edb36311ef85162baa26e4a8205e0bf0`.
