# Local Gramlot examples

The [runner](00-runner/README.md) presents the same native HTML examples in Python
and JavaScript. The twelve paired examples live in [`html_svg/`](html_svg/), and
the runner starts with a [catalogue of the supported HTML grammar](00-runner/catalog/README.md).

This directory is development material. It runs against the current Gramlot
checkout and the local Minimal and Node.js integration checkouts; it is not a
published application or a package release. Shared visual styling lives in
[`../themes/gramlot-base/`](../themes/gramlot-base/).
