# 07 · Bound SVG

SVG attributes take `^` pointers as HTML attributes do. The circle's `r` and `fill`, the bar's `width` and `fill`, and the label text read Data paths edited by the controls.

The ranges have `live` true, so the drawing follows the slider while you drag it. SVG has no style shortcuts: `fill` and `stroke` are SVG presentation attributes.

**Try it:** Bind the circle's `cy` to a third range.
